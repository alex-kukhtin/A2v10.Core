# A2v10.App.Assets2026

Application assets for A2v10 applications

## Syntax highlighting and IntelliSense

In Visual Studio 2026 all three are required:

1. XAML files must have the **`.vxaml`** extension.

2. Install the **A2v10 Xaml Language Service** extension from
[Visual Studio Marketplace](https://marketplace.visualstudio.com/items?itemName=OleksandrKukhtin.a2v10xamlsp).

3. Open `.vxaml` files with the **Source Code (Text) Editor**, not the XML editor:
run the "Open With" context command for any `.vxaml` file, select "Source Code (Text) Editor",
then click "Set as Default".
