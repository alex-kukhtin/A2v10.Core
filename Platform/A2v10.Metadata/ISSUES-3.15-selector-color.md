# 3.15. `ColorProperty` для `SelectorSimple`

Развёрнутое описание к пункту [ISSUES 3.15](ISSUES.md). Решение о цвете, на котором это стоит:
[CLAUDE.md](CLAUDE.md), «Colour: a property of the row, never of the reference».

## Что просится

Грид уже рисует ссылку цветным бейджем: цвет едет с каждым разрешением ссылки
(`SqlBuilder.RefFields`), и `Badge` в индексе спрашивает не тип колонки, а приехал ли цвет. Та же
самая ссылка в карточке и в панели фильтров рисуется обычным селектором — текстом. Экран
разъехался: одна вещь в одном месте цветная, в другом нет, и ничем, кроме контрола, эта разница
не объясняется.

## Почему не бейдж внутри контрола

Закрытое значение селектора лежит в `<input v-model="query">`
(`Web/A2v10.Core.Web.Site/wwwroot/scripts/main.js:7272`) — в то же поле печатают при поиске.
Бейдж туда не положить: это текст элемента формы, а не разметка.

Два обхода взвешены и отклонены:

- **режим `SelectorStyle.ComboBox`** — там значение действительно `<span class="select-text">`, и
  `tag-label` с классом цвета ложится ровно как в `a2-color-combobox`. Цена: пропадает выбор
  набором текста, а справочник берут именно им;
- **бейдж поверх поля вне фокуса** — это переделка контрола, а не свойство, и два разных вида
  одного поля в фокусе и без него.

## Что вместо

`outline`-бейдж и есть «border + color»: прозрачный фон, цвет из класса цвета
(`themes/tabbed/Text.less:19`). Значит покрасить селектор — дать его `.input-group` тот же цвет
в `color` и `border-color`. Закрытое значение перестаёт быть проблемой, контрол не меняется.

Крючок уже стоит на нужном месте: селектор вешает на себя `has-value`, когда включён `highlight`
и значение непустое (`main.js:7446`), а CSS на этот класс красит фон и делает шрифт жирным
(`themes/tabbed/Control.less:312`) — это зелёная рамка, которую видно в панели фильтров сегодня.
`ColorProperty` добавляет туда второй класс — имя цвета.

## Что построить, по слоям

- **C#, вид представлений.** `ColorProperty` рядом с `DisplayProperty`
  (`ViewEngines/A2v10.ViewEngine.Xaml/Controls/Selector.cs:22`) и один `MergeAttribute("color", …)`
  рядом с `display` (`:60`). Аддитивно: опубликованный контракт контролов не ломается.
- **Метаслой.** Проставлять из `TableMetadata.ColorColumn` — тем же полем, которым грид выбирает
  бейдж. Два места не должны иметь двух ответов на «есть ли у строки цвет».
- **SQL.** `FetchAsync` (`Database/SqlBuilderFetch.cs`) шлёт `Id`, `Name` и явно запрошенные
  `inherit`-колонки; цвета там нет, а выпадашка рисуется из него. Дослать тем же правилом, что
  `RefFields` — в обеих ветках `sql`. Диалог `browse` трогать не надо: он рисует грид эндпойнта,
  а грид уже цветной.
- **JS.** Класс цвета в `cssClass2()` рядом с `has-value` (`main.js:7446`); для пунктов списка
  крючок уже есть — `itemClass(itm, ix)` (`main.js:7564`), образец рядом, в `a2-color-combobox`
  (`main.js:6947`).
- **LESS.** Развилка ниже.

## Развилка, и она единственная дорогая: где лежит палитра

Сегодня это 21 имя, выписанное руками в `Text.less`: `&.success, &.green { background-color:
@success-base-color; &.outline { color: … } }` и так далее. Чтобы селектор красился тем же:

- **второй такой же список в `Control.less`** — дёшево и ни на что не влияет, но словарь цветов
  становится **четвёртой** копией (см. 3.12: `TagLabelStyle`, список пикера, `CardStyle`, CSS);
- **каждый цвет один раз кладёт свою переменную** (`--tag-color`), а `.tag-label.outline` и
  `.a2-selector.has-value .input-group` её читают. Список остаётся один, потребителей два — это
  3.12 **сужает**, а не расширяет.

Второй вариант правильный и трогает опубликованную палитру, то есть все экраны сразу. Выбор за
автором палитры; до этого выбора писать нечего — C#, SQL и JS без CSS дадут класс, который
ничего не красит.

## Практическое

CSS здесь собирается Web Compiler'ом из Visual Studio (`compilerconfig.json`), а не из консоли:
правка в `.less` сама не превратится в `.css`. То есть слой LESS — сторона человека, остальные
четыре слоя машинные.

## Что это закрывает и чего не закрывает

Закрывает вид карточки и панели фильтров: ссылка на цветную строку читается одинаково в гриде, в
фильтре и в карточке.

Не закрывает главного отличия селектора от пикера: кандидаты по-прежнему не едут со страницей, их
достают запросом по мере набора. «Кандидаты приезжают с записью, выбор на месте» — это `pick`,
отложен; цвет в него больше не входит (CLAUDE.md, «Colour»).
